24. AUTO INJECT CONFIG UNTUK BOT V1 & BOT V2

Tambahkan sistem otomatis yang melakukan injeksi konfigurasi penuh saat user/admin membuat bot baru.

Semua proses wajib otomatis, tanpa campur tangan user atau admin, full dari backend.

A. Auto Inject Config BOT V1 (NodeJS)

Setiap user/admin membuat bot versi 1:

Sistem wajib:

1. Copy folder template bot dari repo V1
2. Generate folder:
/bots/<userId>/<botId>/
3. Inject otomatis ke file config:

Wajib diinject:
• BOT_TOKEN
• OWNER_TELEGRAM_ID
• USER_ID
• BOT_VERSION (v1)
• PATH LOG
• LIMIT USER
• STATUS PREMIUM

Format config wajib:
config.json atau settings.js sesuai template

4. Aktifkan bot otomatis
5. Cek token valid
6. Jika token invalid → hapus bot + notif user

Log injeksi disimpan di admin panel.

────────────────────────────────────────

B. Auto Inject Config BOT V2 (Python)

Jika user premium atau admin mengaktifkan V2:

Sistem wajib:

1. Copy template repo V2
2. Generate folder:
/bots/<userId>/<botId>/
3. Auto inject ke file config bot V2:

Inject data:
• BOT_TOKEN
• OWNER_TELEGRAM_ID
• USER_ID
• MODE (premium/free/admin)
• VERSION (v2)
• CPU PRIORITY
• API_KEY INTERNAL PANEL
• DATABASE URL BOT
• LIMIT REQUEST
• ENDPOINT PANEL CALLBACK

4. Pastikan config Python valid
5. Langsung jalankan environment
6. Create virtual environment otomatis
7. Install requirements bot versi 2 otomatis
8. Jika token invalid → stop + notif admin + notif user

Log inject wajib masuk:
• Aktivitas Bot V2
• Log admin
• Log user
